Prima di iniziare — una tantum

1. Installa Python

Se non è già installato, scaricalo da python.org. Durante l'installazione spunta "Add Python to PATH".

2. Installa le dipendenze

Apri il Prompt dei comandi nella cartella dello strumento e lancia, una sola volta:

pip install playwright beautifulsoup4 lxml pypdf
playwright install chromium

Il secondo comando scarica il browser Chromium (~150 MB) usato per aprire le pagine dei programmi. Richiede qualche minuto.

Il percorso, passo per passo
1

Esporta da Atlante / MyUniversity

Fai la tua ricerca e esporti il file Excel con gli insegnamenti da analizzare. Salvalo nella cartella dello strumento, così comparirà da solo nel passo successivo.

2

Apri la finestra dello strumento

Doppio clic su Avvia Scarica Programmi.bat. Non serve aprire il Prompt dei comandi né ricordare parametri: scegli il file dal menu a tendina ed eventualmente un ateneo o un limite per una prova.

3

Guarda l'anteprima

Il pulsante Anteprima mostra quanti link sono scaricabili, quanti verranno saltati e perché — senza scaricare nulla. Consigliato prima di un batch grande, per farsi un'idea del lavoro prima di partire.

4

Avvia il download

Il pulsante Avvia download parte subito. L'avanzamento scorre nella finestra riga per riga: tipo di link, ateneo, esito.

Se si interrompe, niente va perso. Ogni PDF è salvato su disco appena scaricato. Rilanciando lo stesso download con gli stessi parametri (senza ordine casuale), lo strumento salta i file già presenti e riprende solo quello che manca.
5

Verifica i PDF scaricati

Il pulsante Verifica PDF scaricati rilegge ogni file e segnala i sospetti: un banner cookie non chiuso in tempo, una pagina quasi vuota, o un insegnamento il cui programma non è ancora stato compilato dal docente. Per quest'ultimo caso non c'è nulla da fare finché l'ateneo non lo pubblica; per gli altri, basta cancellare il file segnalato e ripetere il passo 4.

6

Carica su Matrix Framework Builder

I PDF pronti si trovano nella sottocartella programmi_pdf, con lo stesso nome del file esportato. Apri index.html nella cartella principale (o vai su matrix-framework-builder.netlify.app) e caricali per l'analisi.
